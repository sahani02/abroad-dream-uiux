# 🌍 Abroad Dream – UI/UX Prototype

## 📌 Project Overview
This project is a UI/UX prototype for a student counselling platform that helps users find universities, scholarships, and courses worldwide.

## 🎯 Objectives
- Provide an easy-to-use interface for students
- Allow filtering by country, field, degree, and attendance
- Improve user experience through clean design

## 🧩 Features
- User Registration & Login
- Search University with Filters
- Suggested Universities Page
- About Us Page
- Contact & Help Page
- Profile Page
- Notification Page

## 🎨 Design Decisions
- Color Theme: Blue, White, Black
- Typography: Poppins / Roboto

## 🛠️ Tools Used
- Axure RP
